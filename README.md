# ✉️ AI Email Reply Assistant

An AI-powered email reply generator built with **Spring Boot**, **React**, and a **Chrome extension**.
Paste any email (or open one in Gmail) and instantly get a professional, tone-adjusted reply
generated by Google's **Gemini** model.

> 🎯 Two ways to use it: a standalone **web app** (works on any device) and a **Chrome extension**
> that adds an **"AI Reply"** button directly inside Gmail.

## 🧩 Tech Stack

- **Backend:** Java 21, Spring Boot 3.5, Spring WebFlux (`WebClient`), Gemini API
- **Frontend:** React 19, Vite, Material UI (MUI), Axios
- **Extension:** Chrome Manifest V3 (content script injected into Gmail)
- **Deployment:** Docker + Render (backend), Vercel (web app)

---

## 📸 Features

- 🤖 Generate professional email replies from any email content
- 🎨 Choose a tone: Professional / Casual / Friendly
- 🌗 Light & dark mode in the web app
- 📋 One-click copy to clipboard
- 📨 **Gmail integration** via the Chrome extension — an "AI Reply" button appears in the compose toolbar

## 🚀 Run Locally

### 1. Backend (Spring Boot)

You need **Java 21** and a free **Gemini API key** from https://aistudio.google.com/apikey.

```bash
cd email-writer-sb

# Set your Gemini credentials as environment variables:
#   GEMINI_URL = https://generativelanguage.googleapis.com/v1beta/models/gemini-2.5-flash:generateContent?key=
#   GEMINI_KEY = your-gemini-api-key

# Windows (PowerShell):
$env:GEMINI_URL="https://generativelanguage.googleapis.com/v1beta/models/gemini-2.5-flash:generateContent?key="
$env:GEMINI_KEY="your-api-key-here"

# macOS/Linux:
export GEMINI_URL="https://generativelanguage.googleapis.com/v1beta/models/gemini-2.5-flash:generateContent?key="
export GEMINI_KEY="your-api-key-here"

./mvnw spring-boot:run       # runs on http://localhost:8080
```

### 2. Web App (React)

You need **Node.js 18+**.

```bash
cd emai-writer-react
npm install
npm run dev                  # runs on http://localhost:5173
```

By default the web app talks to `http://localhost:8080`. To point it elsewhere,
create a `.env` file (see [`.env.example`](emai-writer-react/.env.example)):

```
VITE_API_BASE_URL=http://localhost:8080
```

### 3. Chrome Extension

1. Open Chrome and go to `chrome://extensions`
2. Turn on **Developer mode** (top-right)
3. Click **Load unpacked** and select the [`emailWriterExt/`](emailWriterExt/) folder
4. Open [Gmail](https://mail.google.com), open/reply to an email, and click the **"AI Reply"** button in the compose toolbar

> The extension is pre-configured to use the live backend
> (`https://email-writer-sb.onrender.com`). To use a local backend instead,
> edit `API_BASE_URL` at the top of [`emailWriterExt/content.js`](emailWriterExt/content.js).

## ☁️ Deployment

### Backend → Render
The backend deploys automatically from [`render.yaml`](render.yaml) (Docker). Set the
`GEMINI_URL` and `GEMINI_KEY` environment variables in the Render dashboard.

### Web App → Vercel
1. Import this repo on [vercel.com](https://vercel.com)
2. Set **Root Directory** to `emai-writer-react`
3. Framework preset: **Vite** (auto-detected) — build is zero-config
4. Deploy — the app already points at the live backend via `.env.production`

## 📡 API

`POST /api/email/generate`

```json
{
  "emailContent": "Hi, can we reschedule our meeting to Friday?",
  "tone": "professional"
}
```

Returns a plain-text generated reply.
